# SteepWrap — Сайт исследовательского проекта

Информационный сайт школьного исследовательского проекта **SteepWrap**, посвящённого разработке и изучению альтернативных упаковочных материалов с потенциалом биоразложения.

---

## 📁 Структура проекта

Проект реализован на чистом HTML5 и CSS без избыточных библиотек, с использованием лёгкого сборщика **Vite** для локальной разработки и сборки:

```text
├── index.html          # Главная страница (русская версия)
├── ru/
│   ├── research.html   # Страница исследования (RU)
│   └── team.html       # Страница команды проекта (RU)
├── en/
│   ├── index.html      # Главная страница (английская версия)
│   ├── research.html   # Страница исследования (EN)
│   └── team.html       # Страница команды проекта (EN)
├── src/
│   └── assets/
│       └── images/     # Изображения и иллюстрации проекта
├── style.css           # Единая таблица стилей для всех страниц
├── vite.config.js      # Конфигурация локального сервера и сборки страниц
├── package.json        # Манифест проекта и скрипты запуска
├── metadata.json       # Метаданные проекта
├── DEFENSE_GUIDE.md    # 🎓 Шпаргалка для защиты перед жюри конкурса (8 класс)
└── README.md           # Документация проекта
```

> 💡 **Для подготовки к конкурсу:** Обязательно прочитайте файл **[`DEFENSE_GUIDE.md`](./DEFENSE_GUIDE.md)**! В нём собраны готовые ответы на 7 главных вопросов жюри («почему не React?», «как работает адаптивность?», «зачем нужен Vite?» и словарь терминов).

## 🎨 Дизайн-система и эко-стиль

В проекте используется лёгкий, современный эко-стиль с научным характером:

1. **Типографика**:
   - Основной шрифт: `Plus Jakarta Sans` (современный геометрический гротеск с отличной читаемостью на экранах и поддержкой кириллицы/латиницы).
   - Моноширинный шрифт для индексов: `IBM Plex Mono`.
   - Системные фолбэки: `system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif`.

2. **Цветовая палитра (CSS переменные в `:root`)**:
   - `--green-deep` (`#163824`) — глубокий лесной оттенок для заголовков и акцентов.
   - `--green-primary` (`#1e4d33`) — фирменный зеленый цвет проекта.
   - `--green-accent` (`#2d7a4d`) — свежий растительный зеленый для интерактивных элементов.
   - `--green-light` (`#eaf3ed`) — мягкий мятный цвет для бейджей, аватаров и акцентных фонов.
   - `--bg-page` (`#fbfcfb`) — чистый, светлый природный фон страницы.
   - `--bg-surface` (`#ffffff`) — фон карточек с мягкой тенью и тонким контуром.
   - `--text-primary` (`#17241c`) — высококонтрастный графитовый текст (соответствует стандарту доступности WCAG AAA).

3. **Иллюстрации и визуальные материалы**:
   - `eco_packaging_sample_*.jpg` — демонстрация экспериментальных образцов плёнок на основе растительного сырья в главном блоке (Hero).
   - `raw_components_lab_*.jpg` — растительное сырьё и компоненты (направление «Состав материалов»).
   - `testing_measurement_*.jpg` — лабораторные измерения толщины и свойств образцов с помощью цифрового штангенциркуля (направление «Экспериментальная проверка»).
   - `degradation_analysis_*.jpg` — исследование поведения образцов в почвенном субстрате и регистрация данных (направление «Анализ результатов»).
   - *Для замены на реальные фото вашей лаборатории достаточно поместить фотографии в папку `src/assets/images/` и обновить пути в тегах `<img>`.*

4. **Интерактивные элементы**:
   - Закрепленная шапка (sticky header) с полупрозрачным фоном и мягким размытием (`backdrop-filter: blur(14px)`).
   - Двухколоночный главный экран с адаптацией под мобильные устройства.
   - Карточки с микроанимацией подъёма (`transform: translateY(-4px)`) и мягкой тенью при наведении.
   - Аккуратный переключатель языка `RU | EN`.
   - Аватары участников команды с инициалами и чётким разделением ролей.

## 🚀 Запуск на локальном компьютере

### Требования
- Установленный **Node.js** (версия 18 или новее) и **npm**.

### 1. Установка зависимостей
Откройте терминал в папке проекта и выполните:
```bash
npm install
```

### 2. Запуск в режиме разработки
Для запуска локального сервера выполните:
```bash
npm run dev
```
После запуска откройте в браузере адрес:
```
http://localhost:3000/
```

### 3. Сборка проекта для публикации
Для создания оптимизированной статической версии сайта:
```bash
npm run build
```
Собранные файлы будут помещены в папку `dist/`.

Для предварительного просмотра собранного сайта:
```bash
npm run preview
```

## 🔍 Как проверить результат

1. Откройте главную страницу `http://localhost:3000/`.
2. Проверьте отображение иллюстраций:
   - Главная фотография экспериментальных образцов в правом блоке первого экрана.
   - Три тематические лабораторные иллюстрации в карточках направлений.
3. Проверьте навигацию по разделам:
   - Переход в раздел «Исследование» (`/ru/research.html`)
   - Переход в раздел «Команда» (`/ru/team.html`)
   - Переключение на английскую версию (`EN` в шапке)
   - Переход обратно на русскую версию (`RU`)
4. Проверьте адаптивность: уменьшите ширину окна браузера до размеров мобильного экрана — блоки плавно перестраиваются в одну аккуратную колонку без горизонтального скролла.
